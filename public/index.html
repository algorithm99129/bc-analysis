Range density

Target Hits / exp. Density Expected Diff Ratio Deviation Density vs expected

Density = hits ÷ rounds × 100. In a short range large differences are normal; the Deviation column shows whether a difference is unusual for the range size.

⠿

Deviation

Deviation = (hits − expected) ÷ standard deviation. Above 0: the target has hit more often than its default chance; below 0: less often. Shaded bands mark ±1σ and ±2σ — inside ±2σ is ordinary variation.

⠿

Probability board

Target Default Avg every Hits / exp. Observed Deviation Adj. gap Since Due Next in Status Longest Alert

Default = 99% ÷ target (1.98% for 1.00×), average gap = 1 ÷ default. Adj. gap scales the average gap by observed ÷ default rate; Due grows each round since the last hit. Note: the game's own chance for any single round stays at the Default value.
